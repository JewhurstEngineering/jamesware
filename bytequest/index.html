Problem

Most “retro games” are nostalgia skins on modern engines. The fun of an old machine was the constraint: a prompt, a verb, a room.

What it does

A small text adventure you run in a terminal. Rooms, inventory, a save file next to the binary. No account. No live service.

Why it exists

To keep a slot on this site that looks like a finished product page — and to be the template for the next real JamesWare app. Clone this folder.

Capabilities

  • Parser with a short, honest verb set
  • Save / load as a local file
  • Map that fits on one screen
  • Score, but not a leaderboard
  • Runs in a normal terminal
  • No telemetry

How it works

Everything stays on the machine. There is no JamesWare backend and no ByteQuest account. If this page becomes a real product, keep that sentence true or delete it.

Current state

Fictional showcase. Not a shipping game. Use this page as the Coming Soon shell: copy bytequest/, rename the slug, fill the REPLACE comments, point the homepage card at the new folder.

Get it

No download yet. When the next product is real, this strip becomes GitHub, TestFlight, or an App Store link — only the ones that exist.
