Problem

The same cluster of apps every session — game + overlay + chat, or IDE + terminal + browser — clicked one by one from the Start menu.

What it does

Named groups on Windows. One click (or tray) starts the set, in order, with optional delays, flags, and per-app admin.

Why it exists

A helper, not a new desktop. Get into the workflow faster.

Capabilities

  • Named groups from the tray or main window
  • Launch order and delays
  • Command-line flags and Run as administrator per app
  • Curated app list, plus browse to any executable
  • Optional start with Windows
  • Light/dark theme, system tray
  • Aimed at gamers, sim racers/flyers, developers, admins, office routines

How it works

Native Windows app. Groups live on the machine. The download button is the GitHub Release asset, not a fake store badge.

Current state

Released for Windows 10/11 via GitHub Releases. Marketing page lives in the same public repo.
